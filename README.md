# 麗絲迪 (NICEDRAPE Solar Protection System Co., Ltd.) 官方網站

![NICEDRAPE Logo](https://upload.cc/i1/2026/08/12/jiLRXY.png)

本專案為 **麗絲迪 (NICEDRAPE Solar Protection System Co., Ltd.)** 的官方響應式靜態官網，專為展示 60 年品牌底蘊、智能綠色遮陽技術與 SilverScreen 旗艦節能面料而打造。

---

## 🌟 專案特點 (Key Features)

* **品牌傳承與戰略據點**：展示 60 年建築遮陽深厚底蘊，並明確標示香港總部及北京、上海、廣州辦事處的詳細地址、電話、Email 與跨區域職能分工。
* **SilverScreen 旗艦面料專區**：重點呈現超薄金屬鍍鋁塗層技術、四季節能（夏阻熱/冬保暖）、無甲醛/無 PVC 及 100% 可循環再造等綠色特性。
* **9 大遮陽產品系統**：涵蓋捲簾、百葉簾、百摺簾、窗簾路軌、羅馬簾、屏風簾、天幕簾、維迪紗簾及垂直簾。
* **國際權威認證**：標示 ISO 14001、Öko-Tex Standard、Greenguard、USGBC 及助力 LEED / Green Star / BREEAM 綠建築評級加分資訊。
* **7 大領域成功工程實績**：獨立卡片展示酒店、辦公大樓、高級住宅、餐廳、商業機構、醫療機構及學校教育機構的真實案例圖片與工程名稱。
* **精準 Google 地圖標記**：嵌入香港總部（荃灣順豐工業中心）可動式 Google Maps 並定位標記。
* **全響應式設計 (RWD) 與微互動**：針對桌面與行動裝置進行 RWD 優化，搭配自訂 CSS 卡片懸浮動畫與 JavaScript 手機選單。

## 🛠️ 技術棧 (Tech Stack)

* **HTML5**：語意化網頁結構。
* **Tailwind CSS (CDN)**：Utility-First CSS 框架，建構 `#314392` 品牌專屬色系。
* **Custom CSS (`style.css`)**：自訂微動畫、卡片懸浮效果、品牌變數與滾動條美化。
* **Vanilla JavaScript (`script.js`)**：處理手機版選單開關、平滑滾動與表單互動。
* **FontAwesome 6**：向量圖示庫支援。
* **Google Maps Embed API**：香港總部精準地圖嵌入。
