# 麗絲迪 (NICEDRAPE Solar Protection System Co., Ltd.) 官方網站

![NICEDRAPE Logo](logo.png)

本專案為 **麗絲迪 (NICEDRAPE Solar Protection System Co., Ltd.)** 的官方響應式靜態官網，專為展示 60 年品牌底蘊、智能綠色遮陽技術與 SilverScreen 旗艦節能面料而打造。

---

## 🌟 專案特點 (Key Features)

* **品牌傳承與據點**：展示 60 年建築遮陽深厚底蘊，以及香港總部與北京、上海、廣州辦事處的大中華區服務網絡。
* **SilverScreen 旗艦面料專區**：重點呈現超薄金屬鍍鋁塗層技術、四季節能（夏阻熱/冬保暖）、無甲醛/無 PVC 及 100% 可回收等綠色特性。
* **9 大遮陽產品系統**：涵蓋捲簾、百葉簾、百摺簾、窗簾路軌、羅馬簾、屏風簾、天幕簾、維迪紗簾及垂直簾。
* **國際權威認證**：標示 ISO 14001、Öko-Tex、Greenguard、USGBC 及助力 LEED / Green Star / BREEAM 綠建築評級加分資訊。
* **跨領域工程實績**：展示酒店、A 級辦公大樓、高端餐廳與商業機構工程範例。
* **互動式 Google 地圖**：嵌入香港總部可動式 Google Maps，方便客戶與合作夥伴定位。
* **全響應式設計 (RWD)**：針對桌面與行動裝置優化，包含流暢的手機端漢堡選單。

---

## 🛠️ 技術棧 (Tech Stack)

* **HTML5**：語意化網頁結構。
* **Tailwind CSS (CDN)**：現代化 Utility-First CSS 框架，實現快速樣式客製與品牌色系（`#314392`）建構。
* **Vanilla JavaScript**：原生 ES6+ 邏輯（獨立抽離於 `script.js`），處理手機版選單切換與互動體驗。
* **FontAwesome 6**：向量圖示支援。
* **Google Maps Embed API**：地理位置嵌入。
